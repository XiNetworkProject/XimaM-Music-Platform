## Périmètre et méthode

Baseline : `d0ac45379227b4ad86042b6b8eb2156535f1b817`. Les **100 routes initiales** existent toujours ; le laboratoire **`/dev/v2`** porte l’inventaire actuel à **101 routes**. Les endpoints API, fichiers error/layout et surfaces contextuelles ne sont pas comptés comme pages supplémentaires.

La colonne « Avant / source » désigne le point d’entrée existant à cette baseline. Tous les 100 fichiers ont été retrouvés à ce SHA. Les liens ouvrent leur source de travail actuelle ; la version avant s’obtient avec `git show <SHA>:<fichier>`. La revue porte sur les points d’entrée, clients délégués, layouts, classes de composition et différences sources ; elle ne constitue pas un test navigateur de chaque route.

L’inventaire original [routes-initial.json](../artifacts/synaura-v2/routes-initial.json) est conservé intact, y compris ses états initiaux. SHA-256 : `9126263ab7c4fa383d4d32193586d2ae9474d7d7b2e7e6e215aa048344ba10aa`. Ses anciennes classifications automatiques « Redirection » ne sont pas reprises lorsqu’il s’agit seulement d’une garde session conditionnelle.

### Lecture des états

- **IMPLÉMENTÉE** : composition V2 présente en source, directement ou dans le client/cadre partagé nommé. Ce n’est pas un PASS visuel ou métier.
- **CONSERVÉE** : fonction/route maintenue ; cadre adapté, alias, document, administration ou outil explicitement décrit.
- **LEGACY EXPLICITE** : destination historique ou démonstration identifiée, non présentée comme une nouvelle expérience V2 complète.
- **TESTÉ — capture route / fixture** : capture de cette URL dans le navigateur local, données/session de navigateur non persistantes. Aucun login réel, écriture métier ou SSR authentifié n’est attesté.
- **TESTÉ — composant fixture** : vrai composant monté dans `/dev/v2`, pas navigation ni chargement SSR de sa route canonique.
- **BLOQUÉ** : tentative arrêtée par la garde SSR locale ; le screenshot d’authentification ne valide pas l’écran cible. **NON TESTÉ** : aucune preuve V2 applicable trouvée.

Les colonnes mobile/desktop sont des viewports Chromium **390×844 / 1440×900**, pas un appareil Android ou un zoom natif. Une capture d’un composant commun ne vaut pas test de tous ses alias. Synthèse de source : **51 implémentées**, **35 conservées**, **15 legacy explicites**.
